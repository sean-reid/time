# time

An interactive map of how gravity and motion change the passage of time. Plot a course past the Sun, a neutron star, or Sagittarius A* and watch your clock drift from the one you left on Earth. Every number comes from general relativity and published measurements.

## Run

```sh
pnpm install
pnpm dev
```

## Test

```sh
pnpm lint
pnpm check
pnpm test
```

## Deploy

Merges to main deploy to Cloudflare Workers through GitHub Actions. To deploy by hand:

```sh
pnpm deploy
```
